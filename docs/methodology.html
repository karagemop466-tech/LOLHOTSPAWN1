📖 Methodology & sources

How every probability on this site is produced, verified, and refreshed — with links so you can check each step yourself.

1. Match inventory (what we cover)

Primary: Hotspawn's own embedded public fixtures API — the same data play.hotspawn.com renders.

  • Fixtures API: phpstack-1372681-6459848.cloudwaysapps.com/api/v1/fixtures?sport_alias=lol — all LoL fixtures with status, tier, stage, lock time, points, participants, scores.
  • SSR cross-check: play.hotspawn.com/lol-pickems — rendered lobby; we scrape match permalinks + counts and reconcile against the API each run. Mismatches are flagged, never silently dropped.
  • Open match = status scheduled with lock_time in the future. Every row links to its official Hotspawn match page.
  • Not used as a probability input: Hotspawn crowd “% picked”. It is collected for audit only and shown nowhere as a likelihood.

2. Probability sources & precedence

For each match we take the best available line. Order: sharpest book first, prediction market second, own model third.

  1. Pinnacle (market) — guest odds API, no key needed: leagues /0.1/sports/12/leagues (filter League of Legends *; live now: League of Legends - World Championship), matchups /0.1/leagues/{id}/matchups, moneylines /0.1/leagues/{id}/markets/straight (period 0 = series winner). American odds → decimal → implied, then devig: p(team) = (1/dec) / Σ(1/dec). Two-sided markets only; vig is removed proportionally.
  2. Polymarket (market) — gamma-api.polymarket.com/events?closed=false&tag_slug=league-of-legends. Two-outcome team markets; probability = mid of best bid/ask when quoted, else last outcome prices, renormalized to 100%. Thin liquidity (<$500) or wide spread (>0.10) is flagged.
  3. Own model (originated line) — Elo-style rating built exclusively from actual results in the Hotspawn fixtures archive (every ended LoL series with scores): E = 1/(1+10^((R_opp−R)/400)); K = 24 × margin-mult (1+0.25×(|Δgames|−1)) × recency 0.5^(age/365d). Predictions shrink toward 50% for thin history: p = 0.5 + (E−0.5)×min(1,(min(n)+2)/10), clamped to [3%,97%]. Ratings for every team: data/model/ratings.json.

The own-model line is computed for every match with history and shown alongside market lines — when both exist and disagree by >25 points, the match is auto-flagged for review. The pick always follows the precedence above.

3. Confidence labels

  • HIGH — Pinnacle devigged line (sharp, high-limit book), or own model with ≥10 recorded series per side.
  • MEDIUM — Polymarket line with ≥$1,000 liquidity, or model with 3–9 series per side.
  • LOW — thin Polymarket market, or model with 1–2 series per side (early-season rosters).

4. Refresh cadence & pipeline

GitHub Actions runs every 6 hours (requirement: 4–8h) + on demand:

  1. collect — fetch all four sources (3 retries each, browser UA); failures logged, pipeline degrades gracefully and flags gaps.
  2. analyze — rebuild Elo from full results history, match markets to fixtures (exact normalized-name match first; fuzzy token similarity ≥0.66 + ±6h time window, and any fuzzy hit is flagged for review), generate picks + flags, update the pick ledger used for accuracy tracking.
  3. build — render this static site (no client-side dependencies) and verify internal links.
  4. publish — commit data + docs; GitHub Pages serves docs/ from main. Run history: Actions log.

5. Verification policy

  • Every match row links to its official Hotspawn match page; every market line links to the exact Pinnacle matchup or Polymarket event.
  • Values that cannot be confirmed from a source are left blank (“—”) and the match goes to Unresolved or Flagged — never inferred.
  • Inventory is reconciled against the rendered lobby each run; discrepancies are flagged with the specific IDs.

6. Known limitations

  • Market coverage is concentrated on tier-1/2 events (Pinnacle currently prices: League of Legends - World Championship); hundreds of amateur-division matches have no market line anywhere we can verify.
  • The own model measures teams as they appear in Hotspawn's archive — roster swaps, academy/main-team promotion, and smurf/stand-in games are invisible to it. Tier-1 teams appear rarely in that archive (it skews to minor leagues), which is why Worlds-level matches rely on market lines.
  • Cross-source team names are unified by normalization (diacritic folding incl. Ø→O, dropped org suffixes like “Esports/Gaming/Team/Club”, plus a small alias table for major orgs — e.g. HLE→Hanwha Life, LØS→LOS). Every non-exact match is flagged for review.
  • Start-time metadata can disagree across platforms. Verified example (2026-10-21): Hotspawn lists Worlds group-stage matches in hourly slots that differ from Pinnacle and Polymarket's official rules (e.g. Hanwha Life vs Top Esports — Hotspawn 18:00 UTC vs Pinnacle/Polymarket 21:00 UTC / 5:00 PM ET). Displayed times and locks are Hotspawn's (they govern pick submission); discrepancies >90 min are auto-flagged.
  • Hotspawn leaves fixtures in “scheduled” status long after they were supposed to start; those (>24h past start, unplayed) are classified stale, excluded from pick lists, and counted in an info flag.
  • Best-of-1 formats (most minor leagues) are high-variance; even correct probabilities lose often.
  • The Hotspawn SSR lobby is CDN-cached and occasionally 403s; the fixtures API is the authoritative inventory, the page is a cross-check.
  • Polymarket prices move continuously; snapshots are point-in-time (timestamp on every page). Polymarket mid-prices are only used when the order-book spread is ≤6¢, else last outcome prices.
