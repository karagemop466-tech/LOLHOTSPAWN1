<div id="esi-heading-6ade0f94f3478" class="esi-heading ">
  
<h2 class="wp-block-heading">How to Read League of Legends Betting Odds</h2>

</div>


<div id="esi-paragraph-6ade0f94f35ea" class="esi-paragraph ">
    
<p>The best League of Legends betting sites usually display the odds in American style by default. That said, you can switch to decimal or fractional if preferred. The main difference is in how each shows potential returns.</p>

  </div>


<div id="esi-paragraph-6ade0f94f3756" class="esi-paragraph ">
    
<p>Let’s break down <a href="https://esportsinsider.com/explainers/esports-betting-odds-explained">how esports betting odds work</a>:</p>

  </div>


<div id="esi-heading-6ade0f94f3927" class="esi-heading ">
  
<h3 class="wp-block-heading">American Odds</h3>

</div>


<div id="esi-paragraph-6ade0f94f3ac4" class="esi-paragraph ">
    
<p>American odds show what a $100 bet would pay out if the number&#8217;s positive, or how much you’d have to risk to pocket $100 when it’s negative. Here are two examples:</p>

  </div>



<ul class="wp-block-list">
<li><strong>Dignitas to win (+150):</strong> A $100 bet would land $150 in profits, plus your original stake back, making it $250 in total.</li>



<li><strong>T1 to win (-120):</strong> Here, you’d need to bet $120 to win $100 profit. The full payout comes to $220.</li>
</ul>


<div id="esi-heading-6ade0f94f3d24" class="esi-heading ">
  
<h3 class="wp-block-heading">Decimal Odds</h3>

</div>


<div id="esi-paragraph-6ade0f94f3e0a" class="esi-paragraph ">
    
<p><strong>Decimal LoL betting odds tell you exactly how much comes back for every $1 staked</strong>. So if the price shows 2.50, that means a $1 wager returns $2.50.</p>

  </div>


<div id="esi-paragraph-6ade0f94f3ed9" class="esi-paragraph ">
    
<p>It&#8217;s way more straightforward than American lines because <strong>there&#8217;s no need to figure out profit separately or reverse any math</strong>.</p>

  </div>


<div id="esi-heading-6ade0f94f3fbf" class="esi-heading ">
  
<h3 class="wp-block-heading">Fractional Odds</h3>

</div>


<div id="esi-paragraph-6ade0f94f40bf" class="esi-paragraph ">
    
<p>Fractional odds are common in the UK and written as a ratio, like 5/2 or 1/4. To read them:</p>

  </div>



<ol class="wp-block-list">
<li>Take the first number</li>



<li>Divide it by the second</li>



<li>Multiply the result by your stake</li>



<li>Add your original wager after that to get the full return</li>
</ol>


<div id="esi-paragraph-6ade0f950005e" class="esi-paragraph ">
    
<p>So, a $1 bet at 5/1 gets you $6 back. That’s $5 profit plus your original dollar. 4/7 means you win $4 for every $7 bet (a total return of $11).</p>

  </div>

  // visible set is their choice, not ours.
  function done(wrap){
    var row = wrap.querySelector('[data-esi-m]');
    return !!row && row.getAttribute('data-esi-st') === 'settled';
  }

  function promote(){
    document.querySelectorAll('[data-esi-scope]').forEach(function(scope){
      var rail = document.querySelector('[data-esi-pills="'+scope.getAttribute('data-esi-scope')+'"]'),
          on   = rail && rail.querySelector('.on');
      if(on && on.getAttribute('data-g')) return;          // filtered by the reader
      var slots = [], spare = [];
      Array.prototype.forEach.call(scope.children, function(el){
        if(!el.hasAttribute('data-g')) return;             // tab panes are not ours
        (el.hasAttribute('data-all') ? slots : spare).push(el);
      });
      slots.forEach(function(el){
        if(!done(el)) return;
        var rep;
        while((rep = spare.shift())) if(!done(rep)) break;
        if(!rep) return;                                   // nothing fresher to show
        el.removeAttribute('data-all');  el.style.display = 'none';
        rep.setAttribute('data-all','1'); rep.style.display = '';
      });
    });
  }

  // A forgotten tab must not poll for ever. Forty covers a long real session at
  // every tier and bounds the worst case to something a capacity plan can hold.
  var MAX_POLLS = 40, polls = 0;

  function tick(){
    if(document.hidden) return schedule(60000);
    if(++polls > MAX_POLLS) return;
    last = Date.now();

    // Sections first, and unconditionally — a page may carry a refreshable band
    // and no hydrated row at all (a band whose every match has been replaced), and
    // that page is exactly the one with nothing else to save it.
    refreshFrags();

    var want = ids();
    if(!want.length) return schedule(CFG.iv.idle * 1000);

    fetch(CFG.url + '?ids=' + want.join(','), {headers:{'Accept':'application/json'}})
      .then(function(r){ if(!r.ok) throw 0; return r.json(); })
      .then(function(d){
        fails = 0;
        var states = (d && d.matches) || {};
        Array.prototype.forEach.call(rows(), function(root){
          var s = states[root.getAttribute('data-esi-m')];
          if(!s) return;
          paint(root,s);
          // A live-bar item is only entitled to be there while its series is
          // running. Retire it otherwise; the bar re-counts itself below.
          if(root.hasAttribute('data-esi-live-item')) root.hidden = !s.live;
        });
        paintCounts(d && d.counts);
        var bar = document.querySelector('.esi-livebar');
        if(bar && typeof bar.esiSync === 'function') bar.esiSync();
        promote();
        schedule(next(states));
      })
      .catch(function(){
        // Three strikes and we stop. A feed outage must not turn every cached
        // page into a client that retries it for ever — ENUK's image localiser
        // did exactly that and it is why this counter exists.
        if(++fails >= 3) return;
        schedule(60000);
      });
  }

  // Spread the herd.
  //
  // Every reader of one cached page carries the SAME CFG.at, so without scatter
  // every reader whose entry has aged past its TTL fires the instant the page
  // paints: a traffic spike arrives at the origin as an identically-shaped spike
  // of REST calls, which is the one thing a cached site is supposed to prevent. A
  // few seconds of jitter costs a reader nothing and turns that spike into a
  // plateau the endpoint's 20s edge cache can actually absorb.
  function jitter(ms){ return ms + Math.random() * (ms > 0 ? Math.min(ms * 0.25, 10000) : 3000); }

  function schedule(ms){ clearTimeout(timer); timer = setTimeout(tick, jitter(ms)); }

  document.addEventListener('visibilitychange', function(){
    if(!document.hidden && Date.now() - last > 20000) schedule(0);
  });

  // Do not ask a question this page already knows the answer to.
  //
  // CFG.at is when this HTML was RENDERED, baked into whatever the page cache
  // handed the reader — so `age` is the age of their cache entry, and a page
  // younger than its own honesty budget needs no request at all. On a cache MISS
  // that is every time; on a HIT it is however long the entry has been sitting
  // there. That ties the request rate to cache staleness instead of to traffic,
  // which is the difference between a flat cost and one that scales with
  // pageviews on a busy site.
  //
  // A clock that disagrees with the server is treated as stale rather than fresh:
  // fetching once too often is cheap, skipping for ever is the bug.
  var age = (Date.now()/1000) - CFG.at;
  if(!(age >= 0)) age = CFG.ttl;
  // A page that is already older than its budget is a CACHE HIT, and its sections
  // are the stale thing — let the first tick refresh them rather than making it
  // wait out a fragment window it has already spent sitting on disk.
  if(age >= CFG.ttl) lastFrag = 0;
  schedule(age < CFG.ttl ? (CFG.ttl - age) * 1000 : 0);
